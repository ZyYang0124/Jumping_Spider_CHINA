# China Salticid Field Notes
## Visual Refinement + Media Archive Upgrade Prompt

You are improving an EXISTING production website:

Live site:
https://zyyang0124.github.io/Jumping_Spider_CHINA/

Repository:
Inspect the existing repository before making any changes.

Reference site for archival concepts:
https://salticidae.org/salticidImages/

Preserve:

- Astro
- current GitHub Pages deployment
- existing data model unless extension is necessary
- existing Observation-first philosophy

The goal of this sprint is:

> Transform the existing site from a clean, well-structured prototype into a distinctive, editorial-quality personal natural-history website, while adding a lightweight but rigorous photographic archive layer inspired by Salticid Images.

> Natural-history journal × field notebook × photographic archive

# 1. Product identity

The conceptual hierarchy must remain:

```text
OBSERVATION
I encountered a spider.

TRIP
I went somewhere and experienced a place.

SPECIES
What accumulated encounters taught us about a taxon.

MEDIA
The photographic evidence documenting those encounters.
```

The public-facing hierarchy should remain approximately:

```text
Photography
↓
Place + time
↓
Encounter
↓
Field note
↓
Identification
↓
Technical metadata
```

Do not reverse this hierarchy.

The site is not intended to document all jumping spiders in China.

It documents jumping spiders actually encountered by the owner and invited contributors.

# 57. Implementation philosophy

Do not perform a dramatic redesign for its own sake.

The current site already has the right conceptual foundation.

Improve it through:

```text
hierarchy
scale
whitespace
photographic presentation
editorial asymmetry
provenance
traceability
```

not through more decoration.

The objective is to make the site's personality stronger while making its scientific archival structure more durable.

---

# 58. Final guiding statement

At every design decision, ask:

> Does this make the visitor feel closer to the actual encounter with the spider?

If yes, prioritize it.

Then ask:

> Can a researcher still understand exactly what photograph, observation, identification, place, and contributor this information came from?

If yes, the design is succeeding.

The ideal result is:

> Outside: a beautiful personal natural-history journal.

> Inside: a rigorous observation–media–identification evidence chain.

Do not sacrifice either side.
