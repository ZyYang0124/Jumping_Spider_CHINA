关于本站

不是「世界上有哪些跳蛛」，而是「我们在哪里、什么时候、以怎样的方式，遇见过这些跳蛛」。

这是什么

跳蛛观察志（Salticid Notes）是一个由站长与受邀专业伙伴共同维护的个人策展自然史项目，记录我们在野外与日常观察中遇见的跳蛛：活体照片、生境、行为、野外笔记，以及少量的标本与分类学信息。地理范围不限中国——无论记录来自哪里，都以同样的标准呈现。

它不是任何地区的跳蛛完整名录，也不是 GBIF、iNaturalist 或 World Spider Catalog 的替代品，更不是公共鉴定平台。本站的边界由「我们实际观察过什么」决定——没有观察过的物种完全可以不出现。

本站的最高结构原则是：每条记录都始于一次观察，而不是一个物种条目。物种页面永远由观察记录聚合而成；鉴定可以随研究深入而改变，观察的永久编号与链接始终不变。

怎样运转

本站不设公开注册。伙伴由站长逐一邀请，均为可信任的专业跳蛛研究者或自然观察者；他们在 Field Studio 中直接发布自己的观察与影像，质量依赖受邀身份、实名署名与完整的鉴定修订历史，而非审核流程。站长对全站内容承担科学编辑责任。

隐私承诺

精确坐标可能包含敏感的生物信息。本站记录的地点分为四级：精确坐标公开 / 坐标已模糊化 / 仅公开地名 / 位置保密。无论哪一级，模糊化都在数据层完成——公开页面与接口从源头就不会携带未脱敏的坐标，也绝不依赖浏览器脚本来隐藏位置。公开照片一律剥离 EXIF（含 GPS）。

数据与可移植性

观察数据以结构化形式保存（可导出 CSV / JSON），网站永远不会是野外数据的唯一副本。当前版本为纯静态构建，数据库层的完整实现（投稿工作流、审核后台 Field Studio）按开发规划在后续阶段接入。

投稿

如果你是专业研究者或资深自然观察者，希望以伙伴身份加入本站，写信到 yangzy0124@gmail.com。你保留照片版权；敏感情形下地点可由你自行选择模糊化或隐藏。

Colophon

本站使用 Astro 构建的纯静态站点，源数据为类型化 JSON（src/data/）， 经构建期隐私管线（src/lib/privacy.ts）脱敏后生成页面与公开 JSON； 媒体派生图由 sharp 生成并剥离全部 EXIF。 每次发布运行公开数据安全测试（npm run test:privacy）。 部署于 GitHub Pages，源码开源于 GitHub。 投稿工作流与审核后台（Field Studio）按规划在后续阶段接入。
